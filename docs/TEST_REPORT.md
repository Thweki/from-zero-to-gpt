# MVP 验收报告

日期：2026-10-22。环境：Linux，Node 24.19.0，真实系统 Chromium；手机尺寸由 Playwright 的 iPhone 13 配置模拟。

## 通过的验证

| 项目 | 实际结果 | 覆盖范围 |
| --- | --- | --- |
| TypeScript | `npm run check` 通过 | 严格类型检查 |
| 单元与内容 | `npm test`，50 / 50 | 课程字段、严格 KaTeX、知识图、数学函数、导入校验、IndexedDB 读写 |
| CPython | `npm run validate:course`，5 / 5 | 所有参考代码及本章断言；TODO 初始练习确实失败 |
| 浏览器 | `npm run test:e2e`，9 / 9 | 真实桌面 Chromium 8 项、移动 Chromium 模拟 1 项 |
| 生产构建 | `npm run build` 通过 | 静态页面、KaTeX 字体、Worker 和自托管 Python 运行时 |

浏览器测试不是静态组件快照：它实际移动滑块并检查计算值，切换阅读模式、掌握和复习状态，刷新后核对 IndexedDB，保存／恢复问题与下一步，导出 JSON 后修改并导入，检查非法导入不会替换记录，并实际执行五章 Python 参考代码与验收断言。

Python 测试还验证初始 TODO 产生真实 AssertionError，死循环可手动停止且编辑器不锁死，编辑内容和空草稿可保存。Worker 设置的 30 秒超时为运行保护；本轮浏览器测试主要验证手动停止，没有等待完整 30 秒路径，也没有恶意代码安全沙箱验收。

## 实际界面检查与修复

- 检查 1440px 桌面路线页与手机尺寸截图；无页面运行异常与横向溢出。
- 操作函数、线性参数、向量长度与点积；两轴改用相同单位比例，投影几何关系与计算一致。
- 验证深色主题刷新保留，学习问题与下一步刷新后显示。
- 修复空代码草稿被默认模板覆盖、导入时间戳被重置、非法自测选项通过校验、跳过导航链接被误当路由、对话框关闭后焦点没有返回触发按钮、编辑器拦截 Tab 导致键盘无法离开等问题。
- 修正测试用例的搜索歧义（KV 同时匹配 QKV）及桌面／移动测试项目配置；最终通过结果以修正后的完整测试为准。

## 内容正确性

五章区分定义域／陪域／值域、严格线性映射与仿射函数、返回值与打印、欧氏长度、点积与余弦相似度。零向量不显示未定义角度。参考代码与图中计算共用明确的数学定义，各章附原始参考链接。
