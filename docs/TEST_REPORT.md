## 真实 AI 导师

通过官方当前 OpenAI 兼容接口，使用用户指定的 OpenCode Go `deepseek-v4.1-flash`：

- 直接请求返回200，并在提供商响应中确认该模型 ID。
- 开发代理和生产 Node 代理均真实返回200。
- 网页提示模式对未完成 square 只给局部提示／引导；主动选择完整解答后给出实现和逐行解释。
- 刷新保留四条对话；切换到 Scaled Attention 后使用该章上下文，正确解释 `[3,2]×[2,3]→[3,3]`、输出 `[3,4]` 与除以 `sqrt(2)`。
- 生产代理解释负梯度，强调局部、小步条件；实际网页未出现运行错误。

这不是对所有问题、提示注入或数学正确性的保证。导师的默认策略仍是概率模型行为，回答需结合教材和实验验证。

七项导师浏览器测试刻意模拟 HTTP 响应，验证隐私选择、模式、错误／重试、取消、保留新草稿、对话／草稿持久化和未配置路径；它们不被当成真实模型验收。18项代理测试覆盖角色校验、上游不能由浏览器修改、原始错误过滤、上游限流与60秒取消；4项实际 TutorPanel 渲染安全回归确认模型／导入消息不能触发外部图片或原始脚本。

## 真实训练与运行保护

标准库 micrograd：固定seed7、1000步，XOR损失 `1.005623→0.001441`，四点拟合4/4；这不证明泛化。

tiny GPT：CPU PyTorch `2.14.1+cpu`，62,592参数，默认250步实测训练 `3.638757→0.946669`，验证 `3.634244→0.901700`。实际跑通训练／评估／生成／inspect／BPE演示／续训；8项测试含因果性、重载logits、恢复下一次优化器更新一致与实际下降。完整记录和失败生成例子见 `projects/tiny-gpt/VALIDATION.md`。

浏览器死循环测试等待 Worker 明确进入执行状态后，仍能编辑笔记；实际30秒看门狗终止循环并恢复运行按钮。另验证手动停止、错误和空草稿保存。没有服务器端任意代码执行；Worker不是恶意多租户沙箱。

## 本轮修复

- 线上 Worker 不支持 Fetch 的 `redirect: error`；改为 `manual` 并显式拒绝所有非成功状态，既兼容运行时也避免携带凭证追随跳转。

- 导师 Markdown 图片的未经点击第三方请求；禁用图片，并保留安全点击链接。
- 重试旧问题会清空新草稿；只在真正提交该草稿时清空。
- 默认不分享代码／笔记，服务端再次检查分享标记；请求按整体字节预算裁减历史。
- 代数退化方程的 NaN 坐标、导入异常数值、TODO返回契约及实际执行状态反馈。
- 继续保留前轮修复：编辑器Tab焦点、对话框焦点恢复、空代码、导入时间戳和跳过导航。

噪声回归的验收改为对照独立QR最优损失，避免把不可消除噪声当程序缺陷；离线导师模拟保持断线直到用户检查，避免React StrictMode双挂载让测试假恢复。

## 限制

移动验收是Chromium模拟，不是真实iOS/Safari；未完成全面WCAG、屏幕阅读器、Firefox或多标签并发数据验收。真实小模型不代表通用语言能力。内部缓存／量化／LoRA的教学实验未全部整合进tiny GPT工程。站点托管结果和版本以发布回执为准；仅静态部署不含导师API。
