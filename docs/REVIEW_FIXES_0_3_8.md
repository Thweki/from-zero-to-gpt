## 数据与边界

`LearningState.version` 仍为1，新增字段全部可选：`readCompleted`、`experimented`、`codePassed`、`lastVisited`、`observationDraft`、`observationSnapshot`。旧备份不迁移、不假造已阅读或代码验证；导入验证布尔、时间、观察文字长度，导出继续包含全部个人学习数据。单章笔记到达原100000字符边界时不再追加，保留原笔记与观察草稿，避免生成刷新后无法导入的数据。

实验上下文统一通过 `experimentContext` 提取，仅包含当前实验相关的参数、可见公式和结果，不混入未启用的向量／直线控件，不接触私人笔记或编辑器。此处理同时用于选图提问，文字模型仍只接收说明与参数；没有启用图片识别。

用时是编辑参考范围，未做真人学习时长测量。阅读和掌握是自我记录；自测与代码验收只验证本站练习，不是对整个知识点或工程能力的认证。
