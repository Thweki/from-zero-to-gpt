# From Zero to GPT v0.5.0

本版本改善 Windows 暗色界面，重做模型服务连接流程，并加入 GitHub 桌面自更新。

- **暗色外观**：Windows 与其他非 macOS 平台的侧栏、上下文面板和顶部栏使用稳定的不透明背景，提高文字、选中项与控件的辨识度。macOS 在确认原生材质可用时保留透明效果。
- **模型服务**：内置 pi 运行时的 41 个可对话服务入口。选择服务商后粘贴 API Key 或使用服务支持的 OAuth 登录，再选择模型，普通流程无需填写接口地址。
- **订阅登录**：接入 OpenAI / ChatGPT、Claude、GitHub Copilot、OpenRouter、Kimi 等上游提供的认证流程；自动刷新凭据。服务可用性取决于账号权限与服务商政策。Gemini 当前提供 Key 接入，没有个人订阅 OAuth 入口。
- **自定义服务**：保留本地模型与 OpenAI 兼容接口，放在高级设置中。已有自定义配置可继续使用。
- **桌面自更新**：启动检查 GitHub 稳定版本；用户选择下载，通过更新签名校验后再安装重启。检查、下载和安装错误分别提示。
- **验证与发布**：新增本地 CI 预检和推送检查，覆盖源码快照、干净安装、完整浏览器回归、Python 工程、桌面打包与模型运行时。只有同一提交的完整 CI 和三平台构建都通过，才发布安装包。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `from-zero-to-gpt-0.5.0-windows-x64-setup.exe` |
| macOS Apple Silicon / Intel | `from-zero-to-gpt-0.5.0-macos-universal.dmg` |
| Linux x86_64 | `from-zero-to-gpt-0.5.0-linux-amd64.deb` 或 `from-zero-to-gpt-0.5.0-linux-x86_64.AppImage` |

旧版没有更新器，**首次升级到 v0.5.0 需要手动安装**。此后 Windows、macOS 和 Linux AppImage 可使用应用内更新；DEB 用户继续安装新版 DEB。`.app.tar.gz`、`.sig` 与 `latest.json` 是自更新所需资源，常规安装请选择上表的安装包。

桌面包内置模型运行时，无需另装 Node.js 或 Bun。课程和基础 Python 练习仍可离线使用，模型请求需要网络。桌面凭据存入系统凭据库，不随学习数据导出；Linux 需要已解锁的 Secret Service。

更新包签名不等于 Apple Developer ID 公证或 Windows 代码签名，系统仍可能提示未识别开发者。Windows 需要 WebView2；Linux 以 Ubuntu 24.04 或兼容环境为基线，AppImage 仍需满足宿主运行库和 FUSE 条件。Android 不包含在此次桌面发行中。

请用 `SHA256SUMS` 核对下载文件，`release-manifest.json` 记录源码提交和安装包摘要。学习记录保存在当前 WebView 中，升级前可在设置页导出备份。真实订阅账号登录和所有系统版本的安装升级不属于自动化测试覆盖范围。
