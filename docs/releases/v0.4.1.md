# From Zero to GPT v0.4.1

首个 Linux、macOS、Windows 桌面发行版，将六阶段、83 章课程、交互实验、Python 练习与三个独立工程打包到本地应用。

- Linux x86_64：AppImage 与 DEB（Ubuntu 24.04 或兼容环境）。
- macOS：Universal DMG，支持 Apple Silicon 与 Intel。
- Windows x64：NSIS 安装程序，需要 WebView2。
- 内置课程、字体、公式与 Pyodide，无需安装 Node.js 或 Python 即可进行基础学习。
- 模型服务面板支持配置 OpenAI 兼容接口，桌面 API key 保存在系统凭据存储中；导师请求需要网络。
- macOS 原生侧栏材质与 Windows Mica / Acrylic，其他平台保留 CSS 回退。

安装包未配置 Apple Developer ID 签名、公证或 Windows 代码签名，操作系统可能提示未识别的开发者。Linux 模型凭据需要已解锁的 Secret Service；AppImage 仍有系统库及 FUSE 要求。Android 不包含在本次 Release 中。GitHub Copilot 登录流程尚未完成。

下载后按 `SHA256SUMS` 核对安装包；`release-manifest.json` 记录准确源码提交及每个安装包的摘要。源码与构建文件可从本版本标签获取，应用采用 GPL-2.0-only，第三方组件保留各自许可。

学习数据保存在当前应用的 WebView 中；从网页迁移请先导出学习 JSON，再在桌面应用中导入。三平台构建与完整 CI 通过后才发布；自动构建不替代所有系统版本的实机验收。

修复发布验收发现的中文标题导致启动就绪检测失败，以及 Windows Python 探测未优先使用已配置解释器的问题。v0.4.0 候选未通过发布门槛，未公开 Release。
