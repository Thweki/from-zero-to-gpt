# 阅读模式与导师入口 · 0.3.6

用户指出四模式内容重复，并确认导师的问题主要是入口难找、提问前选项过多。本轮保持浅灰绿、单栏和已有学习数据，调整功能归属与对话流程。

| 阅读入口 | 仅在此处提供的内容 |
| --- | --- |
| 直觉理解 | 问题动机、直觉、图形实验、目标／误区、自测 |
| 数学推导 | 定义、计算步骤与公式；精确相同的公式不重复出卡片 |
| 代码实现 | 编程任务、编辑器、运行／错误／测试和参考代码；代码说明只出现一次 |
| 深入研究 | 边界与设计讨论、先修链接、引用、本地项目下载 |

完成状态、暂停和下一章仍是本章共同操作。本章定位会先选择正确模式，再聚焦并滚动到实验／代码／自测。模式切换不会重建LessonReader，未提交的自测选择保留；实验卸载时其运行资源按组件cleanup释放，已记录参数从LessonProgress恢复，代码和运行结果沿用原记录。

页眉“问导师”直接打开对话，默认不先进入笔记。完整导师页点击该入口只聚焦现有输入框，不再打开第二份对话。宽屏按需为助手留出350px，不覆盖教材；窄屏使用可关闭的侧栏，入口保留文字。代码和笔记仍保存在本地，只有主动附上才发给模型；附件可见、可撤回。自部署访问码直接显示在输入区，未填时不能发送，不写入草稿或本地存储。

建议问题依据当前章节与阅读模式生成，点击只填草稿，不触发API调用；用户可以修改后发送。Enter发送、Shift+Enter换行，IME组合输入不发送。回答方式和深度收进可展开设置；默认guide直接解释概念，对当前练习只提供局部提示。完整解答仍需用户在设置中主动选择，只有solution模式的服务端上下文含参考实现。

服务端新增可选readingMode枚举，资料仍从已知章节构建，客户端不能提供上游地址、模型、密钥或system消息。支持旧hint/explain/review/solution请求；缺少新字段有安全默认。当前阅读材料包含深入研究内容，优先回应用户正在看的部分。模型策略不是形式化保证，回答仍需用教材和实验验证。

验证包含83章逐模式内容与功能归属、草稿／参数／自测选择恢复、定位切换、导师一键打开、草稿建议无请求、IME／多行输入、显式分享撤回、访问码及既有安全边界。实际结果见TEST_REPORT和版本回执。界面HTTP测试使用明确标注的模拟服务，不等于模型推理验收；真实模型结果需另行记录。手机边界仍为Chromium设备／触控或窄屏模拟，未做实机及软键盘测试。
