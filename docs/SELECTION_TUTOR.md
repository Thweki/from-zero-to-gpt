# 选中文字与图片，带入导师

## 使用

在教材正文拖选文字，或点击实验图／教材图片，鼠标附近出现「问导师」。点击后打开现有导师框，所选内容显示为可移除的引用。已有问题草稿保留；没有草稿时填写一句可修改的提问。只有按发送才调用模型。再次选择会替换当前引用，不覆盖提问。

Esc、取消按钮、点击选区之外、滚动或切换章节／阅读模式收起浮窗。文字键盘选区可用 Alt+Enter 聚焦浮窗；图像可 Tab 聚焦后 Enter 选择。全屏实验的浮窗在全屏元素内显示，带入时退出全屏，再聚焦导师框。窄屏浮窗限制在可见视口内，不新增常驻操作栏。

引用、问题草稿、主题、章节仍由原 IndexedDB 学习状态保存；刷新后打开导师可继续。引用按章节保存，导出／导入时校验类型和长度。每章对话最多 80 条，其中最近 4 张已发送图像保留本地栅格，其余保留说明；普通文字模型的已发送记录仅保留图表说明。选区超过 3000 字会明显标注节选。选区不会自动包含私密笔记或编辑器内容，原代码／笔记分享开关保持独立。

## 图片能力与边界

现有 OpenCode Go / DeepSeek v4.1 Flash 按文字连接处理，`TUTOR_SUPPORTS_IMAGES` 默认 `0`。图像预览仅在本地；发送的是标题、图内文字、当前结果及选择时的实验数值。界面明确写出「当前模型仅接收图表文字与参数，预览不上传」，服务端也要求模型不得声称看过像素。普通无说明图片可能只有标题，导师不能据此推断图片内容。

后续若配置了已核实支持 OpenAI `image_url` 内容块的视觉模型，可在服务端设 `TUTOR_SUPPORTS_IMAGES=1` 并重新启动／发布。界面据 `/api/tutor/status` 显示能力，发送被明确选中的单张 PNG／JPEG 和说明；客户端不能通过声明模型能力绕过限制。此次保留现有服务端配置，没有更换模型或启用视觉能力。视觉协议的模拟验收不等同于真实视觉模型质量验收。

SVG 在浏览器中克隆当前图像、冻结主题样式、移除脚本／外部引用，转换为最长边 900px、最多 240000 字符的 JPEG。图片和 Canvas 只从已经显示的元素复制像素，不另行获取图片 URL；跨域图片无 CORS、复制失败或过大时，明确退回说明。服务端不获取外部 URL、不接收 SVG／HTML，只有显式启用视觉才提高请求体上限至 320KB；默认仍为 64KB。聊天历史中的图片不会被反复上传，只保留文字上下文。既有密钥、来源校验、访问码、限流、取消和完整解答策略保留。

主要实现：`SelectionTutor.tsx` 处理选区与本地快照，`tutor-selection.ts` 为导入和 API 共享校验，`TutorPanel.tsx` 处理引用／发送，`server/tutor.ts` 控制上游能力。

## 验证边界

新增浏览器场景涵盖选区附近浮窗、草稿保留、刷新恢复、移除、快照不随参数变化、默认不传像素、视觉协议、键盘、退出全屏、窄屏深色及普通图片。单元测试覆盖导入往返、危险／过大数据拒绝及服务端能力约束。模拟提供商验证请求结构，不代表实际模型识图；桌面 Chromium／设备模拟不等于 iOS、Android 实机或软键盘验收。实际执行结果见 TEST_REPORT 及版本化发布回执。
