# From Zero to GPT 产品需求

## 产品目标

为有系统工程经验、需要重建数学基础的独立开发者提供可解释、可操作、可中断的学习实验室。学习的终点是能打开自己写的微型 GPT，解释核心计算的输入、输出、形状、数值和设计动机。

不设置打卡、学习时长、截止日期、排名或惩罚。核心知识和实验不依赖付费模型接口，不需要账号。AI 是未来的引导工具，不能代替练习和思考。

## MVP A 的交付边界

本轮实现规格包含五章真实课程：函数是什么、线性函数与参数、用 Python 表示函数、向量的基本概念、向量点积。全部提供问题与动机、渐进解释、数学定义、可修改 Python、实验、误区、动手任务、自测反馈和引用。

主要页面是日常学习界面：左侧知识导航，中间路线或教材，右侧上下文笔记与恢复信息。路线展示六阶段全貌和依赖；只有已完成教材可进入阅读。后续节点明确标记规划，不创建空白教材。

MVP 包含：

- 可搜索的学习路线，建议先修导航和明确的学习状态。
- 直觉、数学、代码和深入模式，共享章节状态。
- 真实 SVG 数学交互；改变输入、斜率、截距和向量分量时重新计算输出。
- 本地进度、笔记、代码、实验参数、主题和最近位置持久化。
- “保存思路，立即结束”：记录当前问题、下一步、代码和运行结果；下次打开可恢复。
- 全量 JSON 导出与经校验的导入；数据保留在本浏览器，不上传。
- 自托管 Pyodide Web Worker 运行基础 Python，真实输出、错误和断言测试；参考实现由学习者主动展开。
- 深浅主题、键盘可操作控件、移动端布局与无障碍标签。
- 自动化测试、构建和交接文档。

Pyodide 是提前纳入 MVP 的有限功能：支持本组纯 Python 实验，不宣称浏览器具备 PyTorch 训练能力。Python 运行与网页线程隔离，超时可终止 Worker。实际实现和验证状态以 [PROGRESS.md](PROGRESS.md) 与 [TEST_REPORT.md](TEST_REPORT.md) 为准。

## 主要学习流程

1. 打开实验室，看到已有的思路和最近课程；首次访问从函数开始。
2. 选择知识点，查看问题和先修，自选解释层次。
3. 修改实验参数，先预测，再观察图像和数值。
4. 编辑代码，执行断言，阅读运行错误并修正；需要时展开参考。
5. 完成自测，阅读具体反馈，自己决定是否标记掌握或需要复习。
6. 在任何时候记录“我卡在哪里”和“下一步做什么”，保存后结束；以后从相同上下文继续。

## 验收清单

| 要求 | 可观察证据 |
| --- | --- |
| 本地可运行 | README 的安装、启动和构建命令可执行 |
| 路线可导航 | 点击首五节点进入对应真实课程，规划节点无假页面 |
| 数学真实响应 | 参数变动后图形、数值与公式一致 |
| 教材完整 | 每章含解释、实验、任务、自测、引用与参考代码 |
| 状态不丢失 | 修改笔记、代码、参数和状态，刷新后仍存在 |
| 可中断恢复 | 保存问题与下一步，重新打开能读取并继续 |
| 数据可迁移 | 导出再导入保持数据；无效导入不覆盖原状态 |
| 无 API 门槛 | 断开 AI 服务仍能阅读、运行纯 Python 和做数学实验 |
| 适配桌面移动 | 主要操作可见、可点击，内容不依赖悬停 |
| 真实质量报告 | 自动化结果和未覆盖部分明确列出 |

## 后续需求

B 增加更完整的代码实验管理、错误驱动提示、可配置 AI 导师、教材自动化验证和更细的依赖图操作。AI 默认仅提示、提问和局部建议；完整解答须由学习者主动请求。密钥只能保存在可选后端或学习者本地代理的服务端环境，不能放进 Vite 构建或浏览器持久化。
