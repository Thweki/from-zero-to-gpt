# 专注阅读与浅淡主题 · 0.3.5

用户反馈默认界面复杂、操作点过多、浅深外观均太明亮，并明确不喜欢蓝色强调。此次直接调整默认体验。

- 阅读单栏上限840px（正文可用760px），目录和学习工作台默认关闭；页眉入口、Escape与明确关闭按钮可操作。
- 笔记与导师共用一个按需面板，移除常驻重复上下文、问题卡和进度条，保留保存思路入口。
- 四项本章定位合并为一个原生展开菜单；选中位置自动关闭、聚焦并滚动到目标。学习目标／误区、先修／阅读资料／项目下载默认折叠。
- 隐去装饰英文、重复面包屑与状态标签，保留中文层级、16px正文、四种解释、真实实验和自测。
- 浅色背景#f0efe9、浅灰绿选中#e6ebdf；深色背景#1b1d1a、低亮按钮#343f2e，正文#c8cdbf。强调色移除蓝色，字体继续同源交付。
- 颜色、热图权重和真实数值含义保持对应；Attention热图混色上限20%，使最大权重也能看清数字，GPT动作使用独立动作表面。

不迁移IndexedDB；代码、笔记、章节模式、实验数值、主题、导师草稿及学习断点沿用原记录。导航与面板显隐不导出，不建立第二套学习状态。

验收包括默认信息收敛、关闭面板不留隐藏Tab目标、实际跳转、笔记／参数恢复、低饱和动作色与360至1440px布局，以及既有对比度／Python／全屏／断点回归。实际结果见TEST_REPORT与发布回执。边界为Linux Chromium及设备／触控模拟，未覆盖实机、软键盘、Safari或完整屏幕阅读器审计。
