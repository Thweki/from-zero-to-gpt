# 专注阅读与浅淡主题 · 0.3.5

用户反馈默认界面复杂、操作点过多、浅深外观均太明亮，并明确不喜欢蓝色强调。此次直接调整默认体验；后续 UI/UX 重构继续沿用同一学习契约。

- 阅读单栏上限 960px，正文行宽控制在约 72 字符；桌面课程目录常驻，900px 以下改为可聚焦、可用 Escape 关闭的抽屉。笔记和导师工具默认关闭。
- 笔记与导师共用一个按需半透明面板，保留保存思路入口；正文与公式使用实色安静画布，玻璃材质只用于导航和工具。
- 四项本章定位合并为一个原生展开菜单；选中位置自动关闭、聚焦并滚动到目标。学习目标／误区、先修／阅读资料／项目下载默认折叠。
- 保留中文章节层级、16–17px 正文、四种解释、真实实验和自测；下一章是明确的森林绿主操作，暂停入口仍可使用键盘到达。
- 浅色背景 `#f7f7f2`、森林绿选中 `#e7efe7`；深色背景 `#20231f`、正文暖灰 `#cbc7bb`，避免亮白正文与蓝色主操作。字体继续同源交付。
- 颜色、热图权重和真实数值含义保持对应；Attention 热图混色上限 20%，使最大权重也能看清数字，GPT 动作使用独立动作表面。

不迁移 IndexedDB；代码、笔记、章节模式、实验数值、主题、导师草稿及学习断点沿用原记录。导航与面板显隐不导出，不建立第二套学习状态。

验收包括桌面常驻导航、移动抽屉焦点、关闭面板不留隐藏 Tab 目标、实际跳转、笔记／参数恢复、森林绿语义色与 320 至 1440px 布局，以及既有对比度／Python／全屏／断点回归。实际结果见 TEST_REPORT 与发布回执。边界为 Chromium 及设备／触控模拟，未覆盖实机、软键盘、Safari 或完整屏幕阅读器审计。
