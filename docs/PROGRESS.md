## 工程与结果的边界

回归与 micrograd 均用标准库运行。微型 GPT 使用自写注意力、归一化、残差与 MLP，但使用 PyTorch 张量和 autograd；不宣称从零实现 GPU 内核或整个张量求导库。默认语料是原创小规模模板文本，不是商用训练数据。

网页 GPT 实验明确是固定概率表玩具；真实 GPT 训练在本地工程进行。现代 LLM 的缓存、量化、LoRA 等页面采用可核对的小矩阵或估算公式；本地 GPT 目前每步重算，尚未把 KV Cache／量化／LoRA 全部整合进这个工程。

## 接手规则

1. 从 README、TEST_REPORT、ARCHITECTURE 开始，运行现有检查后再改动。
2. 不重命名现有 LessonId。新增 ID 同步 lesson-ids、图、教材、实验与导入校验；保持原五章记录可读。
3. 教材与数学的修改要实际执行参考实现、校验公式及边界值，不靠标题／截图提高覆盖数量。
4. AI 密钥只能在服务端配置；不执行模型生成代码，不自动分享笔记，不把模型回答当数学真值。
5. `public/python/`、下载 ZIP 与构建目录是生成物；`npm run dev`／build 可恢复。虚拟环境、权重和任何 .env 不入 Git。
6. 发布使用现有 `.openai/hosting.json` 的项目身份，保留私有访问设置。源码必须先同步，归档与提交保持一致。
