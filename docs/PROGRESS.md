## 接手注意

1. 已有 `LessonId` 与存储 version 1 是稳定契约；重命名需要迁移。新增课程时同步类型、导入合法 ID、知识图与测试。
2. `public/python/` 来自 postinstall/build，不入 Git；正常 `npm ci` 会恢复。完整 `dist/` 已包含运行时。
3. 用户代码只由浏览器主动执行。不要在 Vite／生产服务进程中添加任意 Python 执行接口。
4. 本地数据不自动同步到部署域名。域名间迁移通过 JSON 导出导入。
5. 当前每次 Python 运行重建 Worker；若将来复用，需保留取消能力和干净 globals，并验证 stdout 与上次任务的状态隔离。
6. 新功能按依赖顺序完成小批真实内容；当前路线中规划节点仅解释先修，不能进入空教材页。
